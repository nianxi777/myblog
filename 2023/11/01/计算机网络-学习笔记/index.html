计算机网络-学习笔记

第1章 计算机网络和因特网

计算机网络（computer network） 主机（host） 端系统（end system） 通信链路（communication link） 分组交换机（packet switch）
传输速率（transmission rate） 分组（packet） 路由器（router） 链路层交换机（link-layer switch） 路径（route或path）
因特网服务提供商（Internet Service Provider，ISP） 传输控制协议（Transmission Control Protocol，TCP） 网际协议（Internet Protocol，IP）
因特网标准（Internet standard） 请求评论（Request For Comment，RFC） 分布式应用程序（distributed application） 套接字接口（socket interface）
客户（client） 服务器（server） 数据中心（data center） 边缘路由器（edge router） 数字用户线（Digital Subscriber Line，DSL）
电缆因特网接入（cable Internet access） 光纤到户（Fiber to The Home，FTTH） 物理媒体（physical medium） 导引型媒体（guided media）
非导引型媒体（unguided media） 无屏蔽双绞线（Unshielded Twisted Pair，UTP） 共享媒体（shared medium） 报文（message）
存储转发传输（store-and-forward transmission） 输出缓存（output buffer，也称为输出队列（output queue））
排队时延（queuing delay） 分组丢包（packet loss） 转发表（forwarding table） 路由选择协议（routing protocol）
电路交换（circuit switching） 分组交换（packet switching） 电路（circuit） 端到端连接（end-to-end connection）
频分复用（Frequency-Division Multiplexing，FDM） 时分复用（Time-Division Multiplexing，TDM） 带宽（band-width）
节点处理时延（nodal processing delay） 排队时延（queuing delay） 传输时延（transmission delay） 传播时延（propagation delay）
节点总时延（total nodal delay） 瞬时吞吐量（instantaneous throughput） 平均吞吐量（average throughput）
协议栈（protocol stack） 自顶向下方法（top-down approach） 报文段（segment） 数据报（datagram） 帧（frame）
封装（encapsulation） 应用层报文（application-layer message） 运输层报文段（transport-layer segment）
网络层数据报（network-layer datagram） 链路层帧（link-layer frame） 有效载荷字段（payload field）

第2章 应用层

概述

端口号（port number） 无状态协议（stateless protocol） 非持续连接（non-persistent connection） 持续链接（persistent connection）
应用程序体系结构：由应用程序研发者设计，规定了如何在各种端系统上组织该应用程序。
两种主流体系结构：客户-服务器体系结构、P2P体系结构
应用层协议（application-layer protocol）定义了运行在不同端系统上的应用程序如何互相传递报文。

web和HTTP

Web的应用层协议是超文本传输协议（HyperText Transfer Protocol，HTTP）
HTTP请求报文的第一行叫作请求行（request line）,其后继的行叫作首部行（header line）
HTTP响应报文有三个部分：一个初始状态行（status line），6个首部行（header line），然后是实体体（entity body）
Web缓存器（Web cache）也叫代理服务器（proxy server），它是能够代表初始Web服务器来满足HTTP请求的网络实体。

电子邮件

3个主要组成部分：用户代理（user agent） 邮件服务器（mail server） 简单邮件传输协议（Simple Mail Transfer Protocol，SMTP）
第三版的邮局协议（Post Office Protocol-Version3，POP3）：110端口
因特网邮件访问协议（Internet Mail Protocol，IMAP）
基于Web的电子邮件：使用HTTP协议

DNS

域名系统（Domain Name System，DNS）：DNS是一个由分层的DNS服务器实现的分布式数据库；一个使得主机能够查询分布式数据库的应用层协议。
DNS协议运行在UDP之上，使用53端口
DNS提供的服务：主机别名、邮件服务器别名、负载分配
递归查询（recursive query） 迭代查询（iterative query）

第3章 运输层

概述

运输层协议为运行在不同主机上的应用进程之间提供了逻辑通信（logic communication）功能
运输层协议是在端系统中而不是在路由器中实现的

多路复用和多路分解

将运输层报文段中的数据交付到正确的套接字的工作称为多路分解。
在源主机从不同套接字中收集数据块，并为每个数据块封装上首部信息从而生成报文段，然后将报文段传递到网络层，所有这些工作称为多路复用。

无连接运输 UDP

特点：（1）关于发送什么数据以及何时发送的应用层控制更为精细（2）无须建立连接（3）无连接状态（4）分组首部开销小

面向连接的运输 TCP

特点：（1）全双工服务（2）面向连接（3）可靠服务
拥塞控制：（1）慢启动slow-start （2）拥塞避免 （3）快速恢复

第4章 网络层：数据平面

概述

两种重要的网络层功能：转发（转发是在数据平面中实现的唯一功能）、路由选择（在网络层的控制平面中实现）
转发（forwarding）是指将分组从一个输入链路接口转移到适当的输出链路接口的路由器本地动作
路由选择（routing）是指确定分组从源到目的地所采取的端到路劲的网络范围处理过程
每台网络路由器中有一个关键元素是它的转发表（forwarding table）

网际协议：IPv4、寻址、IPv6及其他

IPv4：4个字节32比特
子网掩码
分类编址：A类、B类、C类
广播地址：255.255.255.255
因特网的地址分配策略被称为 无类别域间路由选择
动态主机配置协议（Dynamic Host Configuration Protocol，DHCP）

第5章 网络层：控制平面

路由选择算法

路由选择算法（routing algorithm）目的是从发送方到接收方的过程中确定一条通过路由器网络的好的路径
最短路径（shortest path）

链路状态路由选择算法

LS算法是一种使用全局信息的算法。
Dijkstra算法

距离向量路由选择算法

距离向量（Distance Vector，DV）算法是一种迭代的、异步的和分布式的算法。

因特网中自治系统内部的路由选择：OSPF

开放最短路优先（OSPF）
优点：（1）安全（2）多条相同开销的路径（3）对单播与多播路由选择的综合支持（4）支持在单个AS中的层次结构

ISP之间的路由选择：BGP

自治系统间路由选择协议（BGP）
作用：（1）通告BGP路由信息（2）确定最好的路由

SDN控制平面

SDN体系结构具有4个关键特征：（1）基于流的转发（2）数据平面与控制平面分离（3）网络控制功能：位于数据平面交换机外部（4）可编程的网络

ICMP：因特网控制报文协议

ICMP被主机和路由器用来彼此沟通网络层的信息。
最典型的用途是差错报告。

SNMP：简单网络管理协议

简单网络管理协议（Simple Network Management Protocol）是一个应用层协议，用于在管理服务器和代表管理服务器执行的代理之间传递网络管理控制和信息报文

第6章 链路层和局域网

概述

链路层提供的服务：（1）成帧（2）链路接入（3）可靠交付（4）差错检测和纠正
数据链路层负责从一个节点通过链路将（帧中的）数据报发送到相邻的物理节点（一个子网内部的2节点）

奇偶校验和循环冗余检测

循环冗余检测（Cyclic Redundancy Check，CRC）编码。CRC编码也称为多项式编码

信道划分协议

时分多路复用（TDM）
频分多路复用（FDM）
码分多址（CDMA）

随机接入协议

时隙ALOHA
ALOHA
载波侦听多路访问（CSMA）
具有碰撞检测的载波侦听多路访问（CSMA/CD）
